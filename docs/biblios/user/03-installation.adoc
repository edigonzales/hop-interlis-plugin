== Installation

=== Voraussetzungen

[cols="2,3"]
|===
| Komponente | Getesteter Stand
| Apache Hop | 2.19.0
| Java | JDK 21
| Geometry Type Plugin | `hop-geometry-type-plugin` 0.2.0-SNAPSHOT, passend zur getesteten Plugin-Kombination
| Vector/Raster Plugin | `hop-vector-raster-plugin` 0.1.0-SNAPSHOT für das GeoPackage-Tutorial mit `Vector Writer`
| Betriebssystem | macOS, Linux oder Windows
|===

Installieren Sie die gemeinsam getesteten ZIPs. Snapshot-Koordinaten können später andere Artefakte liefern; für eine reproduzierbare Installation halten Sie Artefaktstände und Prüfsummen fest. INTERLIS-Bibliotheken und Hop-Version werden durch den Build vorgegeben.

=== ZIP installieren

Das INTERLIS-ZIP heisst `hop-interlis-plugin-<version>.zip`. Die Maven-Repositories für https://jars.interlis.guru/releases/ch/so/agi/hop-interlis-plugin/[Releases] und https://jars.interlis.guru/snapshots/ch/so/agi/hop-interlis-plugin/[Snapshots] enthalten die verfügbaren Artefakte.

. Hop und laufende Pipelines beenden.
. Beim Update das bisherige Verzeichnis `plugins/transforms/interlis` entfernen.
. Das INTERLIS-ZIP und das Geometry-ZIP direkt in `+$HOP_HOME+` entpacken.
. Für GeoPackage zusätzlich das Vector/Raster-ZIP dort entpacken.
. Hop mit Java 21 neu starten.

[source,text]
----
$HOP_HOME/
  plugins/
    transforms/
      interlis/
        hop-interlis-transforms-<version>.jar
        lib/
          hop-interlis-core-<version>.jar
          ... INTERLIS-Abhängigkeiten ...
      vector-raster/                 # für Vector Writer
    misc/
      hop-geometry-type/
----

H2 wird über Hops JDBC-Classloader verwendet und gehört bereits zu Hop 2.19.0. Es wird nicht zusätzlich ins INTERLIS-ZIP gepackt. Kopieren Sie keine weiteren Geometry-, JTS- oder H2-JARs in das Pluginverzeichnis.

=== Installation kontrollieren

Suchen Sie in Hops Transform-Auswahl nach `INTERLIS`. Erwartet werden Input, Output, Transfer Input/Output, Object to Row, Row to Object, Structure Explode/Collect, Role Join, Validate und Enumerations. Für das erste Tutorial muss auch `Vector Writer` verfügbar sein.

Bei fehlenden Transforms prüfen Sie das Hop-Startprotokoll, die Verzeichnisstruktur und `java -version`. Alte und neue JARs im gleichen Pluginverzeichnis können Classloader-Fehler verursachen.

=== Aus Quellen bauen

[source,bash]
----
git clone https://github.com/edigonzales/hop-interlis-plugin.git
cd hop-interlis-plugin
./mvnw -B -ntp clean verify
python3 scripts/check-distribution.py
----

Die Distribution liegt unter `assemblies/assemblies-hop-interlis/target/`. Die benötigte Geometry-Abhängigkeit muss über die im Repository beschriebenen Maven-Repositories verfügbar sein. Die Entwickleranleitung und `AGENTS.md` beschreiben JDK-Auswahl und CI-kompatible Maven-Einstellungen.

Für den lokalen Entwicklungszyklus:

[source,bash]
----
bash scripts/dev-sync-hop-plugin.sh "$HOP_HOME"
----

Das Skript baut und prüft die Distribution, installiert sie und startet die Hop-GUI neu. Verwenden Sie eine eigene Entwicklungsinstallation.
