= hop-interlis-plugin – Benutzerhandbuch

Dieses Verzeichnis enthält das AsciiDoc-Benutzerhandbuch für das `hop-interlis-plugin`.

== Rendering mit thoth-biblios

Die Dokumentation wird mit https://github.com/edigonzales/thoth[thoth-biblios] gerendert.

=== Konfiguration

Die `biblios.yml` befindet sich im übergeordneten Verzeichnis (`../biblios.yml`).

=== Lokales Bauen

[source,bash]
----
# thoth-biblios JAR bauen (im thoth-Repository)
cd /path/to/thoth
./gradlew :thoth-biblios:build

# Dokumentation bauen
cd /path/to/hop-interlis-plugin/docs/biblios
java -jar /path/to/thoth/thoth-biblios/build/libs/thoth-biblios-<version>-all.jar build \
  --config biblios.yml

# Ergebnis öffnen
open build/docs-site/index.html
----

=== Entwicklungsserver

[source,bash]
----
cd /path/to/hop-interlis-plugin/docs/biblios
java -jar /path/to/thoth/thoth-biblios/build/libs/thoth-biblios-<version>-all.jar serve \
  --config biblios.yml \
  --port 8080 \
  --use-local-working-tree
----
